# Home / Discover

Route: `/`

Home is MovieNight's primary discovery surface.

Its approved design is based on the supplied Movie / Series template references but includes only MovieNight functionality.

## Section order

1. Header
2. Featured Hero
3. Trending Now
4. Popular Movies
5. Discover by Genre
6. Pick for Me CTA
7. Watchlist Preview when appropriate
8. Minimal Footer

Mobile additionally uses bottom navigation.

## Header

Desktop:
- MovieNight identity
- Discover
- Pick for Me
- Watchlist
- Search

Do not add:
- login
- register
- profile
- notification center
- subscription controls

Mobile:
- compact MovieNight identity
- search access
- primary route navigation moves to bottom navigation

## Hero

The Hero is the visual anchor of Home.

Design characteristics:
- large cinematic artwork
- strong visual dominance
- controlled dark gradients for text readability
- movie title
- compact metadata
- short overview
- View Details
- Add/Remove Watchlist
- carousel navigation

Do not use a Watch Movie / Play Movie CTA because MovieNight is not a streaming player.

The supplied template's cinematic composition should be adapted rather than copied mechanically.

## Trending Now

Use a compact horizontal poster rail.

The section should remain independent of genre selection.

Provide a subtle continuation affordance where appropriate.

## Popular Movies

Use the same established movie-card and rail system.

Popular remains independent of genre selection.

Do not merge Trending and Popular.

## Discover by Genre

This is a dedicated discovery section.

Structure:
- section heading
- horizontally scrollable genre controls
- selected genre state
- independent movie result rail

Genre interaction changes only this section's Discover results.

## Pick for Me CTA

Repurpose the visual role of the template's large promotional/banner section.

This is not an award banner.

It promotes MovieNight's signature Pick for Me feature.

Suggested hierarchy:
- short decision-friction headline
- concise supporting copy
- Pick for Me CTA
- cinematic movie imagery/composition

It should visually interrupt the movie rails enough to create rhythm without looking like an unrelated advertisement.

## Watchlist Preview

If the current product behavior supports it, Home may display a lightweight Watchlist preview.

Use a compact horizontal rail.

Do not duplicate the full `/watchlist` experience.

If the Watchlist is empty, prefer hiding the preview or using an intentionally designed minimal state instead of occupying a large portion of Home.

## Footer

Keep the footer minimal.

Potential content:
- MovieNight identity
- essential project/navigation links
- TMDB attribution where required

Do not reproduce the template's large marketing footer.

Exclude:
- FAQ
- studio directory
- subscription links
- large corporate sitemap

## Mobile Home

Use the supplied mobile template as a composition reference.

Key behaviors:
- compact top header
- responsive cinematic Hero
- horizontal movie rails
- horizontal genre chips
- prominent Pick for Me CTA
- optional Watchlist preview
- minimal footer
- Discover / Pick / Watchlist bottom navigation
