# MovieNight Visual Language

The approved Movie / Series Figma template and supplied screenshots are the visual foundation for MovieNight.

The goal is not to invent a new aesthetic.

The goal is to adapt the template's visual language to MovieNight's product requirements.

## Core direction

MovieNight should feel:
- cinematic
- modern
- dark
- premium
- image-first
- compact where movie artwork is presented
- spacious where hierarchy requires emphasis

## Background

Use a deep navy / graphite visual family.

Avoid pure black as the dominant page background.

The background may use subtle tonal variation and controlled gradients to create depth.

## Accent colors

Primary interactive accent:
- cyan / bright blue family

Secondary expressive accent:
- magenta / pink family

Accents must remain controlled.

Avoid turning the interface into a neon dashboard.

## Artwork

Movie artwork is a first-class visual element.

Prefer:
- strong backdrops
- prominent posters
- artwork-led hierarchy
- gradients that improve text readability without hiding artwork

Avoid:
- excessive decorative UI around posters
- cards that visually compete with artwork

## Cards

Movie cards should feel compact and poster-first.

Use:
- restrained corner radius
- subtle border or elevation when needed
- small integrated Watchlist control
- consistent aspect ratio
- horizontal rails on discovery surfaces

Do not wrap every movie section in a large container/card.

## Geometry

Use soft, modern rounded geometry.

Avoid:
- excessive pill shapes everywhere
- oversized SaaS-style rounded panels
- heavy borders around every section

## Effects

Allowed:
- subtle glow
- soft shadow
- image-derived ambient gradients
- selective glass treatment

Avoid:
- permanent strong glow around everything
- excessive blur
- excessive glassmorphism
- ornamental effects that reduce readability

## Typography

Typography should be:
- clean
- contemporary
- highly readable
- visually compatible with the approved template

Use clear hierarchy between:
- display/hero titles
- section headings
- metadata
- body copy
- supporting labels

Avoid a generic enterprise-dashboard appearance.

Do not change the product into a text-heavy interface.

## Section treatment

Prefer an open page composition.

Sections should be separated primarily by:
- spacing
- hierarchy
- occasional background/gradient variation

Avoid excessive divider lines and boxed panels.

## Template adaptation rule

Reuse or adapt template patterns when they serve MovieNight.

Examples:
- Header → adapt
- Hero → adapt
- Movie cards → reuse visual language
- Movie rails → reuse visual language
- Genre controls → adapt
- Collection-style imagery → may inform Watchlist
- Character avatar pattern → may inform Cast

Do not import irrelevant template product semantics.

Remove from MovieNight:
- Series
- Pricing
- Continue Watching
- Kids
- FAQ
- Studios
- Login/Profile

## Original identity

MovieNight may use the template's design language but should not become a literal clone of the template's product.

Functional hierarchy and MovieNight-specific features should make the final interface identifiable as MovieNight.
